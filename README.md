# СИНТЕЗ//77

Концепт интернет-магазина игровых ПК в эстетике цифрового подполья.

**Автор:** Валерий Гацкан ([@DelScream](https://github.com/DelScream))  
**Демо:** [delscream.github.io/sintez-77](https://delscream.github.io/sintez-77/)

Это портфолио-проект. Бренд, товары и цены вымышлены. Это не магазин и не оферта.
